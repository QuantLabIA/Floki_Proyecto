# Cambios v1.4

- Calendario al crear eventos.
- Fecha independiente de la hora de apertura.
- Monto inicial y capacidad opcionales.
- Eliminación administrativa de eventos cerrados con respaldo previo.
- Bloc de listas persistente y autoguardado.
- Conversión directa de mensajes WPS/WhatsApp.
- Vista previa automática de promotores y personas.
- Búsqueda predictiva por nombre.
- Visualización de todas las listas posibles para nombres repetidos.
- Sectores de usuario: boletería y bebidas.
- Bloqueo de acciones cruzadas entre sectores.
- Historial, reportes, cierres y resultados exclusivos para administradores.
- Campo de sector en movimientos para auditoría.
- Migración automática desde versiones anteriores.
