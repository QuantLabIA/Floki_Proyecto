# Floki Manager v2.9.9 — Cierre en Ajustes y evento superior

## Cambios
- El acceso a **Cerrar caja** sale del Dashboard y pasa a **Ajustes / Configuración**, visible solo para administradores.
- El panel de cierre abre el reporte completo antes de confirmar el cierre, manteniendo los cálculos automáticos de ventas, gastos y ganancia neta.
- El cuadro/banner de **Evento abierto** vuelve a la parte superior del Dashboard y ocupa más ancho para funcionar como cabecera del evento.
- El banner del Dashboard ya no ofrece el botón de cierre; conserva únicamente la acción para cambiar la imagen del evento.
- No se modifica la base de datos ni se pierden eventos anteriores.
