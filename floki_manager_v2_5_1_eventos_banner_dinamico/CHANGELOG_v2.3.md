# Floki Manager v2.3 · Candidata final

## Excel de listas

- Nuevo Excel con hoja **Buscador rápido** y hoja **Personas**.
- El buscador encuentra coincidencias mientras se escribe una parte del nombre.
- Incluye promotores, cumpleaños, PROMOS y Lista común.
- Muestra lista de origen, tipo, estado de ingreso, horario y fecha de nacimiento cuando corresponde.
- Orden final: promotores A-Z, cumpleaños, PROMOS y Lista común al último.
- Compatible con Microsoft Excel y WPS Office.

## Cumpleaños corregidos

- Nombre completo y fecha de nacimiento obligatorios.
- Cumpleañero + máximo 9 amigos, con confirmación anticipada al crear la lista.
- FREE hasta las 03:30.
- 50% OFF en toda la carta hasta las 03:00.
- Regalo único de 1 champagne + 2 Speed cuando ingresan 5 o más personas de la lista.
- El cumpleañero debe haber ingresado para habilitar el descuento y el regalo.
- El regalo descuenta stock y se bloquea si faltan productos vinculables.

## Ajustes de cierre

- Se conserva el diseño Floki Minimal Luxe y el logo oficial.
- Se actualizaron textos, tarjetas y estados para mostrar claramente cuándo se habilita cada beneficio.
- La exportación PDF por promotor incorpora fecha de nacimiento y resumen de beneficios en los bloques de cumpleaños.
