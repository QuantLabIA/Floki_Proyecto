# Floki Manager v2.4 · Flujo inteligente

## Interfaz y prioridad operativa

- Login con la identidad visual anterior de Floki (logo vikingo/wordmark).
- Dentro de la aplicación se conserva el logo original de Floki Club.
- El dashboard del administrador muestra primero la carga de listas y stock.
- La operación manual completa del administrador queda en un panel desplegable para reducir ruido visual.
- Boletería abre con el buscador predictivo y sus acciones de venta antes de las estadísticas.
- Bebidas abre con la venta rápida y los beneficios antes de la información secundaria.

## Panel inteligente de listas

- Disponible directamente en el dashboard del administrador y dentro de Listas RRPP.
- Permite pegar texto o cargar PDF/DOCX.
- Detecta automáticamente promotores en mayúscula, PROMOS y Lista común.
- Actualiza únicamente las listas presentes en el contenido cargado; no toca las demás.
- Después de procesar correctamente, el texto del panel queda vacío.
- Se retiraron del panel visible las alternativas CSV/TXT/XLSX para simplificar el uso.

## Importación inteligente de stock

- Carga de stock desde PDF con texto seleccionable o Excel XLSX.
- Detección automática de bebida, marca, presentación, unidad física y cantidad inicial.
- Vinculación automática con variantes existentes.
- Creación de variantes faltantes con precio provisorio de $1.000 para revisión.
- Disponible desde el dashboard del administrador y desde el módulo Stock.
